## Descrição
A dupla tomou uma medida individualista do projeto, onde cada um fazia sua versão de maneira autonoma e ao final comparamos os resultados finais para assim analisarmos as diferentes soluções para o mesmo problema

a versão dessa reposição é do aluno Victor que escolheu a opção de catalogo de jogos porque é fissurado por videogame, assim sendo a descrição de como foi feito o projeto será com base na experiencia deste aluno.

O programa inteira foi escrito inicialmente tendo como base exemplos de código que se encontram nos materias de linguagem de programação 9 e 10 do professor Maromo, depois, foi usado IA como ferramenta para debugar o programa e identificar aonde estavam os erros encontrados, o principal sendo como usar corretamente a função malloc para alocar memória nos vetores de ponteiros.

## Execução
Esse repositório pode ser executado abrindo ele como Projeto no programa CLion. **É necessário alterar o caminho do arquivo de dados**. foi usado a função fflush() para limpar o buffer de input, por isso, o programa pode ser incompatível com certos hardwares e sistemas operacionais.
